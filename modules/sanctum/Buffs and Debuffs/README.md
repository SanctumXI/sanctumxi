# Buffs and Debuffs
Aight, so let's talk about changes.

## UnreliableStatuses

`UnreliableStatuses.lua` gives  Sleep applied by a player or a player's pet to an enemy an independent 8% early-wake chance every 12 seconds. The first possible random wake is at 16 seconds: a successful check warns (50 yards text range), then leaves four seconds of Sleep. Normal expiration also warns four seconds beforehand.
